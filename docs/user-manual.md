# User Manual

## Dashboard
- `Command Center`: Threat overview and alerts
- `URL Sentinel`: Scan URLs
- `Email Scanner`: Paste email/SMS content
- `Image OCR`: Upload suspicious images
- `File Sandbox`: Upload attachments for analysis
- `Threat Reports`: Download reports

## Browser Extension
- Alerts trigger automatically for suspicious pages
- Use the popup to scan the current tab on demand
- Paste your API token into the popup to authenticate scans

## Admin Console
- Placeholder controls for user and policy management
